# Ghostlight

Ghostlight is a tested signaling system that encodes and decodes Morse code over audio beeps, visible light, infrared video, and a covert low-contrast brightness channel hidden in normal video. Developed as a high-reliability signaling prototype for defence-tech applications, the project emphasizes correctness, strict determinism, and verifiable claims over feature breadth.
